# Приложение о самолетах
## Приложение, которое будет собирать данные о самолетах в воздушных пространствах тех стран, которые вы выберете.
1. Клонируйте репозиторий:
```
git clone https://github.com/Veronika-w/Kursovoy_Project2.git
```
2. Установите зависимости:
```
poetry install
```
3. В файле .env.example хранится API-ключ. 
Создайте файл .env из копии этого файла и замените значения переменных реальными данными.

## Основные модули, реализованные в проекте:
- Модуль api_adapter.py. Класс подключается к API и получаем географические координаты стран и информацию о самолетах, находящихся в воздушном пространстве этих стран.
- Модуль airplane.py - используется для работы с информацией о самолетах. Используются методы сравнения самолетов между собой по скорости и высоте.
- Модуль save_info_plane.py. Реализована функция, которая позволяет добавлять информацию о самолете, читать и удалять информацию.
